# Chibi Alarm v0.2

Android Kotlin alarm-clock prototype with GitHub Actions APK build.

## Build
Open Actions > Build Chibi Alarm APK > Run workflow. After success, download the ChibiAlarm-v0.2-debug-APK artifact.

This is a development prototype, not a finished full-featured alarm clock. On Android 16, notification and exact alarm permissions may require manual approval. Test alarms on your own device before relying on them.
